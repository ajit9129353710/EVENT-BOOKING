🎟️ AI EVENT BOOKING PLATFORM

🚀 Discover Events. Book Tickets. Create Memories.

AI Event Booking Platform is a modern full-stack web application designed to make discovering and booking events easier and smarter.

Users can explore upcoming events, view event details, book tickets, and manage their bookings through a simple and user-friendly interface.

Explore. Book. Experience! 🎉

---

✨ Key Features

- 🎫 Event Discovery – Explore upcoming events and activities.
- 🔍 Smart Event Search – Search and discover events easily.
- 📅 Event Details – View event dates, venues, descriptions, and availability.
- 🎟️ Online Ticket Booking – Book tickets through the platform.
- 📱 QR Code Generation – Generate QR codes for booking confirmation.
- 👤 User Authentication – Secure login and registration.
- 📋 Booking Management – View and manage your bookings.
- 🗂️ Event Management – Manage event information.
- 🎨 Modern UI – Responsive and user-friendly design.

⚙️ Installation & Setup

1. Clone Repository

git clone https://github.com/ajit9129353710/AI-EVENT-BOOKING.git

2. Navigate to Project

cd AI-EVENT-BOOKING

3. Backend Setup

cd backend
npm install

Create a ".env" file inside the backend folder:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key

Start Backend:

npm run dev

4. Frontend Setup

Open another terminal:

cd frontend
npm install

Create a ".env" file:

VITE_API_URL=http://localhost:5000

Start Frontend:

npm run dev

🧠 How It Works

1. Users register or log in to the platform.
2. Users explore available events.
3. They select an event and view its details.
4. Users book tickets for their preferred events.
5. The backend processes and stores booking information.
6. A QR code can be generated for booking confirmation.
7. Users can view their booking details.
